# Student Management System

## Project Overview

The Student Management System is a simple menu-driven Python application developed as a first-semester college project.

The application allows users to manage student records through a command-line interface. It provides options to add, view, search, update, and delete student records.

The program also calculates grades based on marks and stores student information using a JSON file.

## Features

- Add student records
- View all student records
- Search students using roll number
- Update student information
- Delete student records
- Automatically calculate grades
- Store student data locally
- Handle invalid user input
